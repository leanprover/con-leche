### con-leche run / description
.lake/build/bin/con-leche --verified --jobs=4 "$IN" 
 [**con-leche**](https://github.com/leanprover/con-leche) is an external
Lean checker with a consistency proof: if it accepts a set of
declarations, then they have a model in set theory (ZFC with enough
inaccessibles) — one set per constant under which every constant is a
member of its type — and in particular no theorem of `False` is accepted.
The proof is done directly against a set-theoretic model, not against
an abstract typing relation; the parser and the Lean runtime are
outside it.

Written in Lean, entirely by Claude under close human guidance. It
runs in verified mode here (the mode the theorem is about) with four
worker threads for the check phase. Slower than the official kernel,
but fast enough for real proofs. It accepts only the three standard
axioms and declines streams that use others.

### nanoclo run / description
timeout 3600 target/release/nanoclo config.json < "$IN" || exit 1
 
 **nanoclo** — a Lean 4 kernel based on *delayed substitutions*.
Terms in flight are closures over interned environments.

Forked from [nanoda_lib](https://github.com/ammkrn/nanoda_lib). Entering
a binder extends the environment in O(1); a variable occurrence reads its
entry through skew-binary jump pointers; substitution into a body happens
only when a type leaves the checker.

Conversion is [sokonanoda](https://github.com/intgrah/sokonanoda)'s
(Apache-2.0), as is the fast path of the export parser.

The modifications from the original nanoda_lib were written by Claude
(Anthropic), directed by Sebastian Graf.


### mathgraph run / description
target/release/sokonanoda config.json < "$IN" || exit 1
 
 MathGraph explores a verifier-guided approach to machine reasoning: treat
failed or inefficient attempts as structured residuals rather than discarded
search.

Each residual asks: what is the minimal refinement of the current
representation needed to eliminate it? Candidate refinements are tested by
external verification; those that survive become reusable constraints, while
counterexamples refine the remaining search space.

This checker applies that process to a fork of
[sokonanoda](https://github.com/intgrah/sokonanoda). Arena profiling exposed
concentrated cost in environment handling; controlled intervention and
ablation isolated the retained optimizations. Changes that improved local
measurements but failed the full semantic gate were discarded.

residual → conjecture → minimal refinement → verification → retained
constraint → new residual

Developed by [Metalogic Labs](https://mathgraph.org/).
