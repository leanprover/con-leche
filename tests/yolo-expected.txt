# with suite ∈ {arena, e2e}, and <fixture>/[mode] spelled exactly as in
# tests/arena-expected.txt resp. tests/e2e-expected.txt.  A fixture with
# no line here is expected to give, under SETLEC_NO_PROOF_CERTS=1, the
# same exit code the certified stack gives.
#
# This file exists for ONE class of entry: the acknowledged class-B
# divergence.  The measurement stack (Setlec/Kernel/CoreNC.lean, task
# #76) skips the per-argument application check everywhere — and
# `inferSpineNC` drops the whole per-argument `infer`, not merely the
# argument-vs-domain `defeq` — so a stream whose only defect is
# *inside an application ARGUMENT* can be accepted under yolo while
# the certified stack rejects or declines it.  The escaping defect can
# be any of: an application type mismatch; a wrong universe-argument
# count on a constant; an application of a non-function; a binder
# whose domain is not a sort; an unsupported projection shape.  (Fuzz
# campaign 2026-08-27, finding F1 — the earlier wording of this
# paragraph said "an application type mismatch" and understated the
# mode.)  A fixture like that is not a bug; it gets a line here, with
# a comment naming the defect it stops detecting.
#
# The certified side of such a pair need not be a *reject*: an
# unsupported feature reachable only from an argument is a positive
# decline (2) certified and an accept (0) under yolo, so a 2-vs-0 pair
# belongs here on the same terms as 1-vs-0.  Nothing about the line
# format changes — the override simply replaces whatever exit code
# tests/e2e-expected.txt (resp. tests/arena-expected.txt) records.
#
