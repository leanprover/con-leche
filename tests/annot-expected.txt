# Expected exit codes for the annotated fixture suite (task #161),
# read by tests/arena.sh (0 accept, 1 reject, 2 decline, 3 error).
# Line format: "<expectation> <fixture>".
#
# These are hand-written export streams (tests/annot/*.ndjson) whose
# lam/forallE records may carry the optional "pw" sort-annotation
# field: absent or "never" claims the binder's codomain is never a
# proposition — the parse placeholder the annotate pass overwrites.
# The named-list form (an array of name-table indices: "zero exactly
# when all those level parameters are zero") was RETIRED with the
# packed positional pw datum (DESIGN.md, 2026-09-06, user ruling): a
# parse-table node is shared across declarations, so a name list has
# no positional reading at parse time, and the annotate pass writes
# every datum anyway.  A stream carrying it is positively declined at
# the record (exit 2) in every mode — which is what the three
# annot_decline_* fixtures now exercise (they still decline, one layer
# earlier).  Every other fixture had its "pw" arrays stripped: the
# annotate pass computes the datum for every binder, and the verified
# mode (--set-model, the default) validates every datum it wrote
# against the codomain sort it computes; annotations never steer
# reduction.
#
# Task #161 P5 (the annotate pass): the pass WRITES the datum wherever
# the input carries the parse placeholder (an absent "pw" field, or the
# semantically identical "never").  The three annot_fill_* streams (the
# pre-P5 decline fixtures, whose offending binder was simply
# UNANNOTATED) accept: the pass fills their placeholders correctly.
# They are kept as the pass's own per-site regression; since the
# packed datum every fixture below is in that situation.

# The write's OUTWARD THREAD (task #161 P5; task #163 clone-drift
# regression).  Two declarations, each a telescope that MIXES a written
# and an unwritten binder — the shape whose annotated output tells the
# repaired fold (`annotateBindersOutI` threads the datum just written,
# via `annotBinderMetaI`) apart from the pre-repair one (which
# re-stamped the leaf's datum at every node).  Nothing in the suite
# exercised it before, which is how a clone of the pre-repair fold
# survived 223-fixture parity.
#  * idmDrift.{u,v} : ∀ (α : Sort (max u v)) (a : α), α — the INNER ∀
#    and λ spell the datum "[v,u]", the outer binders are unannotated,
#    so the leaf computes "[u,v]" and the two folds write different
#    outer spellings of the same zero-ness.
#  * fDrift.{u} : ∀ (α : Sort u), let z := α; ∀ (b : z), z — the ∀
#    telescope's residual is a `letE` whose zeta reduct is a ∀, so the
#    leaf phase takes `annotPwPiI`'s forall-residual head read (the
#    other half of the drift) and picks up that node's written "[u,u]".
# Both accept: every datum reaching a node under either fold is in the
# same `PropWhen.equiv` class (the codomain rule gives one true datum
# per telescope), so the spellings differ but no verdict does — which
# is the fact this fixture pins.
0 annot_pw_thread.ndjson
